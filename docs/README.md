# Resume Maker — Documentation

## Overview

Resume Maker is a full-stack web application that lets users create tailored, AI-powered resumes for specific job applications. Users manage their career history once and generate targeted resumes for any job by pasting in a job description. AI (Claude) rewrites their experience bullets and summary to match the role. Users can also select any text in a generated resume, leave a comment requesting a change, and have AI apply the edit surgically.
